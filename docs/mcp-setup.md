# Qingflow MCP 产品界面

Qingflow MCP 是面向 AI Agent 的在线工作界面，支持：

- 用自然语言查询和处理应用记录；
- 协作处理待办、审批和流程任务；
- 搭建应用、字段、视图、报表和门户；
- 按当前 Qingflow 账号权限执行操作。

普通用户无需安装 MCP 服务、配置本地 stdio、管理 access token 或复制 credential。访问官网即可开始：

[立即体验 Qingflow MCP](https://qingflow.com/product/qingflowMcp)

本仓库保留 MCP skill 和开发参考，主要用于 Agent 能力说明、产品文档和企业私有化接入评估，不作为普通用户的安装入口。
